# DP Plans · วางแผนไฟและช็อตจากมุมบน

เว็บแอป (PWA) สำหรับช่างภาพและทีมถ่ายทำ ใช้วางผังห้อง ไฟ กล้อง และนักแสดงจากมุมบน ผูกภาพบล็อกช็อตเข้ากับ Shot list แล้วส่งออกให้ทีมงาน
ข้อมูลเก็บในเครื่องผู้ใช้เท่านั้น (IndexedDB) และใช้งานออฟไลน์ได้

เปิดแอป: https://hyebronde.github.io/memory-ticket-booth/shotplan/
(บน iPad / iPhone: Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม)

แอปนี้แยกจากแอปตั๋วหนังอย่างสมบูรณ์ ทั้งไฟล์ ฐานข้อมูล และ service worker

## ฟีเจอร์
- **ห้อง:** สร้างห้องสี่เหลี่ยมตามขนาดจริง วาดผนังเอง (จุดปลายดูดติดกันและล็อกมุม 45°) หรือนำเข้าภาพแปลนหรือภาพสแกนแล้วตั้งสเกลจากระยะที่รู้ความยาวจริง
- **ไฟ:** Softbox, Fresnel, Lantern, Panel, Tube, PAR, HMI, Practical แสดงลำแสงตามมุม ระยะ อุณหภูมิสี (K) / RGB และ dimmer รวมวัตต์และกระแสที่ 220V ให้อัตโนมัติ
- **ชุดไฟของฉัน:** บันทึกไฟที่มีจริง (รุ่น วัตต์ ประเภทสี) แล้วนำไปวางบนแปลนได้ทันที
- **กล้อง:** มุมรับภาพ (FOV) คำนวณจากเซนเซอร์และเลนส์จริง แต่ละกล้องมีสีของตัวเอง
- **คน กริป พร็อพ:** นักแสดง ทีมงาน Reflector, Flag, Diffusion, C-stand, ประตู, หน้าต่าง (แสดงแสงธรรมชาติ), เฟอร์นิเจอร์
- **วาดบนแปลน:** ลูกศรการเคลื่อนไหว ปากกา วัดระยะ ข้อความ
- **Shot list:** ทุกช็อตผูกกับกล้องบนแปลน แตะช็อตแล้วมุมกล้องจะถูกไฮไลต์ แนบภาพบล็อกช็อต / reference ได้ (ถ่ายจากกล้องหรือเลือกจากคลัง)
- **ซีน:** หลายซีนต่อโปรเจกต์ ทำซ้ำซีนพร้อมแปลนเดิมได้
- **ส่งออก:** PDF Breakdown (A4 ซีนละหน้า: แปลน + ช็อต + ภาพ + ไฟ + กล้อง), ภาพสรุป PNG, ภาพแปลนอย่างเดียว, Shot list CSV (Google Sheets / Excel), รายการอุปกรณ์, ไฟล์โปรเจกต์สำหรับส่งต่อให้ทีม
- Undo / Redo, pinch-zoom, ปุ่มลัดบนคีย์บอร์ด (V W A P M T, R หมุน, ⌘Z, ⌘D, Delete)

## ไฟล์
- `index.html`: หน้าตาและสไตล์
- `app.js`: ตัวแอปทั้งหมด (ไม่มี dependency และมีตัวสร้าง PDF ในตัว)
- `sw.js`: แคชสำหรับใช้งานออฟไลน์ (scope เฉพาะ `/shotplan/`)

## แผนต่อไป
- แอป iOS (Swift + Apple RoomPlan) สำหรับสแกนห้องด้วย LiDAR แล้วสร้างแปลนอัตโนมัติ
- จำลองทิศแสงอาทิตย์ตามเวลาและทิศของหน้าต่าง
- แชร์ลิงก์ให้ทีมดู / คอมเมนต์ร่วมกัน
